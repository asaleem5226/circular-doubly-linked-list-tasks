# Circular Doubly Linked List Tasks

Three C++ data structure tasks implemented using Circular Doubly Linked Lists. The programs use dynamically allocated nodes and do not use arrays or vectors to store their main data.

## Task 1: Browser Tab Manager

File: browser_tab_manager.cpp

Manages browser tabs: opening and closing tabs, moving between tabs, displaying them forward or backward, and searching by tab ID.

Compile and run:
    g++ -std=c++17 -Wall -Wextra -pedantic browser_tab_manager.cpp -o browser_tab_manager
    ./browser_tab_manager

## Task 2: Circular Photo Album

File: task2_photo_album.cpp

Manages photos: adding at the end, inserting after the current photo, removing photos, navigating, displaying forward or backward, searching, and counting.

Compile and run:
    g++ -std=c++17 -Wall -Wextra -pedantic task2_photo_album.cpp -o task2_photo_album
    ./task2_photo_album

## Task 3: Train Coach Navigation System

File: task3_train_coach.cpp

Manages train coaches: adding, inserting, removing, navigating, displaying clockwise or anti-clockwise, searching, finding the coach with the most available seats, and reversing the train direction by swapping node links.

Compile and run:
    g++ -std=c++17 -Wall -Wextra -pedantic task3_train_coach.cpp -o task3_train_coach
    ./task3_train_coach
